# Archive (과거 팀 프로젝트 이력 및 증빙)

이 디렉터리는 [AI-HealthCare-05/AH_05_04](https://github.com/AI-HealthCare-05/AH_05_04) 팀 프로젝트 시절에 작성된 의사결정, 검증 결과, 테스트 증빙을 보존하는 아카이브입니다.

- **현재 동작·계약의 기준이 아닙니다.** 현행 구조와 계약은 [문서 인덱스](../README.md)의 정본 문서(`docs/architecture.md`, `docs/api.md`, `docs/contracts/` 등)를 우선 참고하세요.
- 일부 계약/평가 테스트가 과거 증빙 파일 경로와 SHA-256 해시를 검증하므로, 아카이브 파일의 본문은 임의로 수정하지 않고 보존합니다.

## 구성

- `decisions/`: 과거 팀 단계의 일자별 결정 기록 (`docs/governance/decisions/`에서 이관)
- `validation/`: 과거 단계의 릴리스·RAG·Track B 검증 리포트 및 JSON fixture (`docs/validation/`에서 이관)
- `testing/`: 과거 이슈별 테스트 증빙, 계약 추적표, DB 로직 baseline (`docs/testing/`에서 이관)
